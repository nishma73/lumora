# LUMORA — Modern Essentials

A modern, responsive lifestyle and technology product store built with HTML, CSS, and vanilla JavaScript.

LUMORA focuses on clean visual design, smooth interactions, responsive layouts, and a simple e-commerce-style shopping experience.

## 🌐 Live Demo

**Live Website:**  
https://lumora-mu-five.vercel.app

**GitHub Repository:**  
https://github.com/nishma73/lumora

---

## ✨ Features

- Responsive modern e-commerce interface
- Product browsing and category organization
- Individual product detail pages
- Add to Bag functionality
- Shopping bag with quantity controls
- Remove products from the bag
- Dynamic cart total
- Cart persistence using `localStorage`
- Light and dark theme toggle
- Client-side routing
- Responsive mobile layout
- Smooth hover effects and subtle animations
- Accessible semantic HTML
- Lazy-loaded product images
- Responsive design for desktop, tablet, and mobile

---

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure
- **CSS3** — Responsive layouts, CSS variables, animations, and modern styling
- **JavaScript (ES6+)** — Application logic and interactions
- **LocalStorage API** — Shopping bag persistence
- **Vercel** — Production deployment
- **Git & GitHub** — Version control and source management
